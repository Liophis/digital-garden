### Registers 寄存器

```

|   CX (CH|CL)  ; 计数器                |
|   DX (DH|DL)  ; 数据                  |
+---------------------------------------+
| 指针 & 变址寄存器 (16-bit)            |
|   SP          ; 栈指针                |
|   BP          ; 基址指针              |
|   SI          ; 源变址                |
|   DI          ; 目的变址              |
+---------------------------------------+

+---------------------------------------+
```

#### 通用寄存器 General-Purpose Registers GPRs

1. **AX (Accumulator Register): 累加器**
    
    - **16位:** AX
        
    - **8位拆分:** AH (高8位) 和 AL (低8位)
        
    - **主要作用:**
        
        - 最常用于算术运算（加、减、乘、除）。很多指令默认就使用 AX。
            
        - 乘法运算中，AX 乘以一个 8 位数，结果放在 AX；乘以一个 16 位数，结果的高 16 位放在 DX，低 16 位放在 AX。
            
        - 函数调用的**返回值**通常放在 AX 中。
            
2. **BX (Base Register): 基址寄存器**
    
    - **16位:** BX
        
    - **8位拆分:** BH 和 BL
        
    - **主要作用:**
        
        - 唯一一个可以作为**内存寻址**中基址的通用寄存器。例如 MOV AX, BX，就是把 BX 寄存器里的值作为内存地址，取出该地址的数据放入 AX。
            
3. **CX (Counter Register): 计数器**
    
    - **16位:** CX
        
    - **8位拆分:** CH 和 CL
        
    - **主要作用:**
        
        - 在循环 (LOOP 指令) 中用作**循环计数器**。每次循环，CX 的值会自动减 1。
            
        - 在位移（SHL, SHR）等操作中指定移动的位数。
            
4. **DX (Data Register): 数据寄存器**
    
    - **16位:** DX
        
    - **8位拆分:** DH 和 DL
        
    - **主要作用:**
        
        - 配合 AX 进行乘除法运算，存放结果的高 16 位或被除数的高 16 位。
            
        - 用于端口 I/O 操作，指定端口号。

#### 指针和变址寄存器 Pointer and Index Registers

1. **SP (Stack Pointer): 栈指针**
    
    - **作用:** 永远指向**栈顶**。它和 SS（栈段寄存器）配合使用，定位栈顶的物理地址。PUSH（入栈）和 POP（出栈）指令会自动修改 SP 的值。
        
2. **BP (Base Pointer): 基址指针**
    
    - **作用:** 通常用作一个**固定的基准点**来访问栈中的数据。SP 会随着 PUSH/POP 而改变，但 BP 在一个函数调用期间通常被设为该函数栈帧的底部，保持不变。这样就可以通过 [BP+偏移量] 的方式方便地访问函数参数和局部变量。
        
3.  **SI (Source Index): 源变址寄存器**
    
    - **作用:** 在字符串或内存块操作中，用作**源地址**的指针。通常和 DS（数据段寄存器）配合。
        
4. **DI (Destination Index): 目的变址寄存器**
    
    - **作用:** 在字符串或内存块操作中，用作**目标地址**的指针。通常和 ES（附加段寄存器）配合。

#### 指令指针寄存器 (Instruction Pointer Register)

- **IP (Instruction Pointer)**
    
    - **作用:** 存放**下一条要执行指令的偏移地址 (Offset)**。它与 CS（代码段寄存器）共同决定了 CPU 要执行的指令的完整物理地址。你不能直接修改 IP 的值，但 JMP（跳转）、CALL（调用）等指令会改变它。
    - Offset：偏移量，即相对位置。

#### 标志寄存器 (FLAGS Register)

- **FLAGS**
    
    - **作用:** 一个 16 位的寄存器，由多个 1 位的标志组成，用于记录 CPU 的状态和上一步算术/逻辑运算的结果。
        
    - **常用标志位:**
        
        - **ZF (Zero Flag):** 结果是否为零？
            
        - **SF (Sign Flag):** 结果是否为负？
            
        - **CF (Carry Flag):** 无符号数运算是否产生进位/借位？
            - 小减大借位，或者溢出进位。
            
        - **OF (Overflow Flag):** 有符号数运算是否溢出？
            - 同符号数运算得到其他符号数

#### 段寄存器 (Segment Registers)

这是 16 位架构最核心且独特的概念，用于解决寻址问题。因为 16 位寄存器，而 8086 处理器有 20 根地址线。
**解决方法：分段寻址 (Segmented Addressing)**  
内存被划分为若干个逻辑段（Segment），每个段最大 64KB。物理地址由两部分组成：**段地址:偏移地址**。
**物理地址计算公式: 物理地址 = 段地址 × 16 + 偏移地址** (等效于 段地址 << 4 + 偏移地址)

- **CS (Code Segment): 代码段寄存器**
    
    - 存放当前正在执行的**代码所在段的段地址**。与 IP 配合，形成 CS:IP 来取出指令。
        
- **DS (Data Segment): 数据段寄存器**
    
    - 存放**数据所在段的段地址**。大多数内存访问指令默认使用 DS。
        
- **SS (Stack Segment): 堆栈段寄存器**
    
    - 存放**堆栈所在段的段地址**。与 SP 和 BP 配合，形成 SS:SP 来定位栈。
        
- **ES (Extra Segment): 附加段寄存器**
    
    - 一个额外的数据段，主要在字符串操作中与 DI 配合使用。
