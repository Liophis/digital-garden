1. 基础概念
   - 离散型：分布律 (PMF) -> 表格或公式
   - 连续型：概率密度 (PDF) -> f(x)
   - 通用：分布函数 (CDF) -> F(x) = P(X <= x)

2. 核心分布模型
   [离散]
   - B(n, p): n次独立重复试验成功次数
   - P(λ): 稀有事件发生次数 (n大p小可近似B(n,p))
   [连续]
   - E(λ): 无记忆性的等待时间
   - N(μ, σ²): 误差分布 (必考标准化变换 Z = (X-μ)/σ)

3. 核心工具：函数的分布
   - 分布函数法 (万能思路)：
     步骤1: 写 F_Y(y) = P(g(X) <= y)
     步骤2: 转化为 P(X 在某区间)
     步骤3: 对 y 求导得 f_Y(y)

## 本章节核心

### 题型一：泊松近似与离散分布计算

- **识别信号**：题干出现“$n$ 很大，$p$ 很小”，或者直接给出“平均每单位时间发生 $\lambda$ 次” 。
    
- **必备知识点**：泊松定理（当 $n \ge 20, p \le 0.05$ 时，二项分布 $B(n, p)$ 近似为泊松分布 $P(\lambda)$，其中 $\lambda = np$） 。
    $$P(X = k) = \frac{\lambda^k \cdot e^{-\lambda}}{k!}$$
    
- **标准步骤**：
    
    1. 明确随机变量 $X$ 的实际意义 。
        
    2. 判定分布类型并写出参数（计算 $\lambda = np$） 。
        
    3. 利用对立事件公式简化计算（如 $P(X \ge 2) = 1 - P(X < 2)$） 。
        
- **高频错误与规避**：直接死算二项分布导致计算量爆炸。**规避：** 看到 $n=1000$ 这种大数字，立刻条件反射想到泊松近似 。

### 题型二：连续型分布与反常积分

- **识别信号**：已知概率密度 $f(x)$ 含有未知常数，或者要求某区间的概率、求分布函数 $F(x)$ 。
    
- **必备知识点**：密度的规范性 $\int_{-\infty}^{+\infty} f(x) dx = 1$，分布函数定义 $F(x) = \int_{-\infty}^{x} f(t) dt$ 。
    
- **标准步骤**：
    
    1. 利用规范性列出积分方程求解未知参数 $A$ 。
        
    2. 求 $F(x)$ 时，必须**分段积分**，注意积分上限是变量 $x$。
        
    3. 计算概率 $P(a < X < b) = F(b) - F(a)$ 。
        
- **高频错误与规避**：求 $F(x)$ 时漏掉 $x \le 0$ 的部分，或者积分上下限写错。**规避：** 永远画出数轴，分段写出 $F(x)$。

### 题型三：连续型随机变量函数的分布（重难点）

- **识别信号**：已知 $X$ 的密度 $f_X(x)$，求 $Y=g(X)$ 的密度 $f_Y(y)$（如 $Y=X^2$, $Y=e^X$, $Y=|X|$） 。
    
- **必备知识点**：分布函数法（万能法）。
    
- **标准步骤**（以分布函数法为例）：
    
    1. 写出 $Y$ 的分布函数定义：$F_Y(y) = P(Y \le y) = P(g(X) \le y)$ 。
        
    2. 确定 $Y$ 的取值范围（极其重要！不在范围内的 $y$，$f_Y(y)=0$）。
        
    3. 将不等式 $g(X) \le y$ 转化为 $X$ 的区间，代入 $X$ 的分布函数或积分 。
        
    4. 对 $y$ 求导得到 $f_Y(y)$ 。
        
- **常见变式**：非单调函数（如 $Y=X^2$），需要解出 $-\sqrt{y} \le X \le \sqrt{y}$ 。
    
- **高频错误与规避**：忘记讨论 $y$ 的取值范围，直接套公式导致错误。**规避：** 第一步永远先写出 $Y$ 的值域。

## 错题归类报告

基于你在 PDF 中的作答和常见学生痛点，我们做如下归类分析：

#### 1. 概念理解偏差类

- **典型表现**：在 Q26 中提问“这个是必须查表吗？” 。
    
- **根因**：对正态分布的性质及实际计算手段认识不足，误以为可以通过直接积分求出精确值。
    
- **纠正动作**：牢记**标准正态分布的积分表是解决所有正态概率问题的唯一工具**。
    
- **防再错检查清单**：遇到 $X \sim N(\mu, \sigma^2)$ 求概率，第一步是否已经将其转化为 $P(Z \le \frac{x-\mu}{\sigma})$？
    

#### 2. 推导链断裂/细节遗漏类

- **典型表现**：Q35 求 $Y=2X^2+1$ 时，对绝对值和复合函数的链式求导处理容易出错 。
    
- **根因**：对于非单调函数 $g(X)$，不等式变形时没有考虑到对称性或负半轴的情况。
    
- **纠正动作**：放弃取巧的“公式法”，老老实实使用“分布函数法”推导 。
    
- **防再错检查清单**：写出 $F_Y(y)$ 表达式后，是否标明了 $y$ 的取值范围？求导时是否对上下限都进行了求导（复合函数求导法则）？
