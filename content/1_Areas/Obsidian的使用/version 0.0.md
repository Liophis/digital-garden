### Part 1: 基础入门与核心理念

#### 1. 安装与创建你的第一个“仓库 (Vault)”
- **下载安装**：从 [Obsidian 官网](https://obsidian.md/) 下载对应你操作系统的版本。
- **创建仓库**：仓库 (Vault) 就是你存放所有笔记的文件夹。启动 Obsidian 后，选择“创建新仓库”。给它取个名字（比如 `CS-Notes`），然后选择一个你电脑上的文件夹位置。
- **核心理念**：你的所有笔记都是 `.md` 文件，明文存储在你的本地电脑上。这意味着**数据永远属于你**，你可以用任何文本编辑器打开它们，非常安全和自由。

#### 2. 认识 Obsidian 的界面
- **文件浏览器 (左侧)**：显示你仓库中的所有文件夹和文件。
- **编辑器 (中间)**：你编写笔记的地方。Obsidian 支持实时预览，你写的 Markdown 会立刻渲染成最终样式。
- **侧边栏 (右侧)**：默认显示当前文件的**反向链接 (Backlinks)** 和**出站链接 (Outgoing Links)**。这是 Obsidian 的精髓所在。

#### 3. Obsidian 的超能力：双向链接
这是你必须掌握的核心功能。在传统的笔记中，你从 A 链接到 B，这是一个单向链接。在 Obsidian 中，当你链接到 B 时，B 也会自动知道 A 链接到了它。

- **如何创建链接**：输入 `[[`，然后开始输入你想要链接的笔记名称。比如 `[[数据结构]]`。
- **好处**：当你学习“链表”时，你可能会写到：`链表是一种基础的[[数据结构]]`。当你将来复习“数据结构”这篇笔记时，右侧的“反向链接”面板会告诉你，“链表”这篇笔记提到了它。知识就这样自动连接起来了！

### Part 2: 专为 CS 学生打造的核心功能

#### 1. 记录数学笔记 (LaTeX 支持) ✍️

Obsidian 内置了对 LaTeX 的支持（通过 KaTeX 库），你不需要安装任何东西就可以直接使用。

- **行内公式 (Inline Formula)**：用一对 `$` 包裹。
  - **示例**：`二次方程的求根公式是 $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$`
  - **效果**：二次方程的求根公式是 $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$

- **块级公式 (Block Formula)**：用两对 `$$` 包裹。
  - **示例**：
    ```
    $$
    \int_a^b f(x)dx = F(b) - F(a)
    $$
    ```
  - **效果**:
    $$
    \int_a^b f(x)dx = F(b) - F(a)
    $$

- **CS 常用数学符号示例**：
  - **求和**: `$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$` -> $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$
  - **大O表示法**: `$O(n\log n)$` -> $O(n\log n)$
  - **矩阵**:
    ```
    $$
    \begin{pmatrix}
    a & b \\
    c & d
    \end{pmatrix}
    $$
    ```
    效果:
    $$
    \begin{pmatrix}
    a & b \\
    c & d
    \end{pmatrix}
    $$

**Pro-Tip**: 当你记算法复杂度、离散数学或线性代数时，这个功能会非常有用。

#### 2. 记录代码笔记 💻

你已经熟悉 Markdown 的代码块，Obsidian 在此基础上做得更好。

- **代码块与语法高亮**：使用三个反引号 ` ``` ` 并指定语言。
  - **示例 (Python)**:
    ````
    ```python
    def bubble_sort(arr):
        n = len(arr)
        for i in range(n):
            for j in range(0, n-i-1):
                if arr[j] > arr[j+1]:
                    arr[j], arr[j+1] = arr[j+1], arr[j]
    ```
    ````
- **代码块自带复制按钮**：鼠标悬浮在代码块上，右上角会出现一个“复制”按钮，非常方便。

- **使用“Callouts”来解释代码**：Callouts (引述块的变种) 是组织笔记的利器，特别适合解释代码。
  - **语法**: `> [!类型]`
  - **示例**：
    ```markdown
    > [!NOTE] 笔记
    > 这是冒泡排序的核心逻辑，通过相邻元素的比较和交换。

    > [!TIP] 优化提示
    > 可以加入一个 flag 来检测某次遍历是否发生了交换，如果没有，说明数组已经有序，可以提前终止循环。

    > [!WARNING] 注意
    > 冒泡排序的时间复杂度是 $O(n^2)$，在数据量大时性能较差。
    ```
    这会让你的笔记结构清晰，重点突出。

### Part 3: 进阶技巧与插件推荐

Obsidian 的强大之处在于其可扩展性。通过“核心插件”和“社区插件”，你可以把它打造成完全符合你需求的工具。

#### 1. 必装的核心插件 (自带，在“设置”中开启)

- **Canvas (画布)**: **强烈推荐！** 这是一个无限画布，你可以在上面放置笔记、图片、卡片，并用箭头连接它们。
  - **CS 用途**:
    - 绘制数据结构（如树、图）。
    - 绘制算法流程图。
    - 设计系统架构图。
    - 整理一门课程的知识脉络。

- **Templates (模板)**: 帮你节省大量重复工作。
  - **创建模板**: 创建一个 `Templates` 文件夹。在设置 -> Templates 中指定它。
  - **示例**: 你可以创建一个“算法笔记模板”：
    ```markdown
    ---
    tags: 算法, 
    date: {{date}}
    ---
    
    # [[{{title}}]]
    
    ## 1. 算法思想
    
    ## 2. 伪代码/核心代码
    ```python
    
    ```
    
    ## 3. 复杂度分析
    - 时间复杂度: $O()$
    - 空间复杂度: $O()$
    
    ## 4. 相关题目
    - 
    ```
  - **使用模板**: 点击侧边栏的“插入模板”按钮或使用快捷键即可。

- **Daily Notes (每日笔记)**: 记录每天的学习进度、待办事项、灵感闪念。

#### 2. 推荐的社区插件 (在“设置” -> “社区插件”中关闭安全模式后浏览安装)

1.  **Excalidraw**: 一个功能更强大的画板插件，可以直接在 Obsidian 里画图，非常适合手绘流程图和架构图。
2.  **Dataview**: **神器级插件**。它能让你用类似 SQL 的查询语言来聚合和展示你的笔记。
    - **示例**: 你可以在一篇索引笔记中，自动列出所有带 `#数据结构` 标签的笔记。
      ````
      ```dataview
      LIST
      FROM #数据结构 
      ```
      ````
3.  **Git**: 对于 CS 学生来说，用 Git 来给你的笔记做版本控制和备份是再自然不过的了！这个插件可以让你在 Obsidian 内部自动或手动地 `commit` 和 `push` 你的笔记到 GitHub/Gitee 仓库。**强烈推荐，数据安全第一！**
4.  **Latex Suite**: 增强 LaTeX 的编辑体验，例如通过快捷键快速输入常用符号、自动补全环境等，写复杂公式时能提升很多效率。
5.  **Tasks**: 增强版的待办事项管理。你可以用它来追踪课程作业、项目 deadline 等。

### Part 4: 一个 CS 学生的实践工作流示例

假设你在上《数据结构》这门课：

1.  **建立结构**: 在你的仓库中创建一个 `CS/数据结构` 文件夹。
2.  **创建索引页**: 在该文件夹下创建一个 `_Index_数据结构.md` 的文件。这个文件是这门课的总览。
3.  **上课/学习**: 学习到“二叉搜索树”时，创建一个新笔记 `二叉搜索树.md`。
4.  **记笔记**: 在 `二叉搜索树.md` 中，你会这样写：
    ```markdown
    ---
    tags: #数据结构 #树
    ---
    # [[二叉搜索树]]
    
    二叉搜索树 (BST) 是一种特殊的[[二叉树]]，它满足以下性质：
    - ...
    
    ## 性能分析
    - 插入: 平均 $O(\log n)$，最坏 $O(n)$
    - 查找: 平均 $O(\log n)$，最坏 $O(n)$
    
    ## C++ 实现
    > [!TIP] 关键点
    > 核心在于递归地维护节点的大小关系。
    
    ```cpp
    struct Node {
        int key;
        Node *left, *right;
    };
    
    // ... 具体实现代码 ...
    ```
    
    ## 与[[平衡二叉树]]的对比
    普通的二叉搜索树在极端情况下会退化成[[链表]]，因此需要[[AVL树]]或[[红黑树]]这样的[[平衡二叉树]]来保证性能。
    ```
5.  **建立连接**:
    - 在 `_Index_数据结构.md` 中，加入一行 `- [[二叉搜索树]]`。
    - 你在笔记中自然地链接了 `[[二叉树]]`、`[[链表]]`、`[[平衡二叉树]]` 等概念。
6.  **回顾**: 当你复习时，打开“图谱视图 (Graph View)”，你会清晰地看到“数据结构”这个中心节点，以及它和“树”、“链表”、“排序算法”等概念是如何连接在一起的。这种视觉化的网络图，对形成知识体系非常有帮助。
